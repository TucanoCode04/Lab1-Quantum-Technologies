# Quantum Technologies Lab: QKD and single-photon detection

Lab report for the Quantum Technologies course (Politecnico di Torino).

- **BB84:** demonstration of the BB84 quantum key distribution protocol, with key sifting and error analysis on measured data.
- **Single-photon detectors:** SPAD avalanche operation and single-photon OTDR measurements.
- **Backflash security:** how photons emitted by a detector's avalanche (backflash) can leak information in QKD systems.

The report (LaTeX source and PDF) is in `report/`.

The data analysis of the SPAD (its detection efficiency, zero-flux efficiency and other parameters) is in `SPAD_characterization/.`folder, use the *requirements.txt* file to install the required package (pip install -r 'requirements.txt').
